# Instruções do backend

Aplicam-se as [instruções comuns](../AGENTS.md). Leia [.agents/BACKEND.md](../.agents/BACKEND.md), [arquitetura](../docs/architecture/ARCHITECTURE.md) e o contrato do módulo afetado.

Preserve autoria/privacidade, versões e execuções imutáveis, Decimal/UTC, transações e API estável. Schema via Alembic; integração em banco exclusivo. Dados oficiais/cálculo exigem também [.agents/FISCAL.md](../.agents/FISCAL.md). Não modificar frontend sem coordenação.
