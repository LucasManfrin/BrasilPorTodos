# Features do frontend

`auth` reúne sessão/formulários e acesso protegido; `contribution` reúne editores/painel/administração; `data-explorer` reúne Brasil Atual, fontes, cards/drawer, gráficos e filtros. `contexts` e `graphs` oferecem contextos/evidências e exploração de relações; `ideas` reúne captura e preparação acessível; `panel` organiza o espaço privado. Rotas ficam em src/app; UI reutilizável em src/components; acesso API/tipos/helpers em src/lib.

Reutilizar contratos/componentes existentes; regra de domínio definitiva pertence ao backend. Instruções em [frontend/AGENTS](../../AGENTS.md), [design](../../../docs/design/DESIGN.md) e [exploração](../../../docs/design/DATA_EXPLORER.md).
