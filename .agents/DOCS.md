# Agente de documentação e colaboração

Leia [instruções comuns](../AGENTS.md), [índice/padrão](../docs/README.md), [estado](../docs/project/STATUS.md), [backlog](../docs/project/BACKLOG.md), [contribuição](../CONTRIBUTING.md) e [publicação](../docs/governance/PUBLICATION.md).

Português claro; um documento principal por assunto. Links relativos, Markdown UPPER_SNAKE_CASE, índices README e regras AGENTS. Raiz somente entradas do projeto/GitHub e configuração; documentos de produto/arquitetura/dados/design/desenvolvimento/governança nas pastas correspondentes. Perfis em .agents.

STATUS é a leitura atual; BACKLOG tem aceite/evidência/dependências; DECISIONS registra justificativas; CHANGELOG/VERIFICATION conservam história datada. Não reescrever resultado antigo como teste atual nem apagar pendências. Mudança de caminho atualiza links, referências em código/comandos e a lista obrigatória do check-docs.

Fonte oficial exige definição/unidade/território/período/preços/termos, sem números de memória. MIT não relicencia dados externos. Política em proposta não é vigente; repositório público não significa serviço lançado. Não inventar URL de repo, canal privado, auditoria ou CI executada.

Ao concluir, executar npm run check:docs e revisar nomes/links no diff. Atualizar backlog imediatamente com evidência real. Não publicar/push/issues externos por conta própria. Para guias futuros, manter caminhos portáveis e evitar dados locais/segredos.
